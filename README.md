# Eye Movement Studio

A browser-based visual tracking and paced-breathing studio. Follow a moving moon across a dark, star-filled scene, adjust the experience, and use the gentle visual environment for attention and relaxation practice. It is an exploratory wellness tool, not a validated clinical EMDR treatment.

## Purpose

An immersive night-sky eye-movement and breathing studio with a moving moon, adjustable pacing, and minimal visual distractions for personal practice and exploration.

## Getting started

Open `index.html` in a modern browser, or publish the repository using GitHub Pages. The interface is intended for personal exploration and learning.

## Scope

This is an independent educational or personal-practice project. Features, accuracy, and browser support should be verified before relying on the app for consequential decisions.
